# More Details

## Rate and storage limits

* Un-encrypted messages are blocked to recipients outside cryptonoise.org but setting up contact via QR invite codes
  allows your messages to pass freely to any outside recipients.
* You may send up to 60 messages per minute.
* You can store up to 100M messages on the server.
* Messages are unconditionally removed latest 20 days after arriving on the server. Earlier, if storage may exceed 
  otherwise.

## Account deletion

If you remove a cryptonoise.org profile from within the Delta Chat app, then the according account on the server,
along with all associated data, is automatically deleted 60 days afterwards.

If you use multiple devices then you need to remove the according chat profile from each device in order for all
account data to be removed on the server side.

If you have any further questions or requests regarding account deletion please send a message from your account to
contact@sr2.uk.
