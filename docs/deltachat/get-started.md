# Get Started

Start by [downloading the Delta Chat app](https://get.delta.chat/).
If you've got the app on your device, [get a cryptonoise.org chat profile](dcaccount:https://cryptonoise.org/new).
If you've installed the app on another device, scan this QR code with the app:
